# Responsive Website Demo

A one-page responsive site built with React 18, JavaScript, HTML and CSS (Vite for the dev server).

## Run
```
npm install
npm run dev
```
Open http://localhost:5173 and resize the browser to see the layout change (3 columns, 2 columns, 1 column with a hamburger menu).

## Build for production
```
npm run build
```
The output goes to the `dist` folder.
